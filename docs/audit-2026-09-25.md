# Review of Wabot 1.4.0 — 2026-09-25

## Fixes

- A timer whose reminder text has no ping no longer requires *Mention Everyone*, and no longer warns about it.
- The editor rejects templates that become empty once optional markers are removed. Length limits account for emoji and expanded variables.
- A malformed zKillboard record no longer blocks later killmails. Name lookups have a timeout, and unavailable names fall back to IDs.
- A PvP alert attempt is recorded *before* the Discord request. A lost response or a restart mid-send no longer pings the same losses again. An uncertain delivery is logged, and may mean one alert is missed.
- Concurrent scans are serialized. A database write error before sending leaves the fight to retry once the database is reachable again.
- Saving connection settings keeps unsaved edits to messages and PvP settings. Forms scroll on smaller windows.
- Fixed broken Polish characters in the manual and the feature summary.

## Statistics editing

**Statistics / leaderboard** can correct a player's completions in Kino, Niarja or Archee, reset them to zero, or add a player manually by Discord ID. `/stats` and `/rank` use the corrections, and new completions add on top.

Each correction records its date and the value before and after. Corrections don't change scheduled reminders. Editing requires a stopped bot and the database lock, and a stale read can't overwrite a newer score. The history stays in database backups. The schema upgrades automatically to version 3.
